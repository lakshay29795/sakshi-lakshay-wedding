## 📝 Deploy in 3 Steps

### Step 1: Login to Vercel

```bash
cd /Users/ltanwar/repos/planning-proj/wedding-website
vercel login
```

**What happens:**
- Browser opens
- Confirm your email/GitHub
- CLI gets authorized
- You see: "Success! Email verified"

---

### Step 2: Deploy

```bash
vercel --prod
```

**Answer the prompts:**

```
? Set up and deploy "~/wedding-website"? [Y/n] 
→ Press Y

? Which scope do you want to deploy to?
→ Select your account (use arrow keys)

? Link to existing project? [y/N]
→ Press N (creates new project)

? What's your project's name?
→ Type: wedding-template-demo (or any name you want)

? In which directory is your code located? ./
→ Press Enter

? Want to modify these settings? [y/N]
→ Press N
```

**Then wait...**
- Uploading files...
- Building...
- Deploying...
- **Done! ✅**

---

### Step 3: Get Your URL!

After deployment, you'll see:

```
✅ Production: https://wedding-template-demo.vercel.app
```

**That's your live website!** 🎉
