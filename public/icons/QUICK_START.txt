📱 HOW TO SET YOUR ANDROID APP LOGO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: PREPARE LOGO
━━━━━━━━━━━━━━━━━━━
• Get your logo/photo (square, 512x512 or larger)
• Save as PNG format
• Name it: logo.png


STEP 2: ADD LOGO TO PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━
• Copy logo.png to this folder:
  wedding-website/public/icons/logo.png


STEP 3: GENERATE ALL ICON SIZES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Open terminal in project root
• Run these commands:

  cd wedding-website/public/icons
  ./generate-icons.sh

• This creates all 8 required icon sizes!


STEP 4: DEPLOY
━━━━━━━━━━━━━━━
• From wedding-website folder:

  git add .
  git commit -m "Add PWA app icons"
  git push

• Wait for Vercel to deploy (automatic)


STEP 5: TEST ON ANDROID
━━━━━━━━━━━━━━━━━━━━━━
1. Open your website in Chrome (Android)
2. Menu (⋮) → "Add to Home screen"
3. See your custom icon! 🎉


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🌐 ALTERNATIVE METHOD (NO CODING)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If you prefer not to use terminal:

1. Visit: https://www.pwabuilder.com/imageGenerator

2. Upload your logo image

3. Click "Generate" and download ZIP file

4. Extract all PNG files to:
   wedding-website/public/icons/

5. Commit and push:
   git add .
   git commit -m "Add PWA app icons"
   git push

Done! 🚀

💡 LOGO DESIGN TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ GOOD:
   • Square aspect ratio (1:1)
   • Simple, recognizable design
   • High contrast colors
   • PNG with transparent background
   • Centered elements
   • 512x512 or larger

❌ AVOID:
   • Rectangular images
   • Too much text
   • Complex details
   • Elements near edges
   • Low resolution
   • JPEG format

❓ TROUBLESHOOTING

Q: Script won't run?
A: Run: chmod +x generate-icons.sh

Q: Icons not showing on Android?
A: 1. Clear browser cache
   2. Uninstall PWA from home screen
   3. Re-add to home screen
   4. Check all icon files exist

Q: Icons look blurry?
A: Use higher resolution source image (1024x1024)

Q: Wrong icon showing?
A: Clear cache and reinstall PWA
