## 🎯 Quick Reference

### Configuration Files Location
All configuration files are in: `/config/`

### Main Config Files
1. `website.config.ts` - Basic settings
2. `content.config.ts` - Text & stories
3. `assets.config.ts` - Media paths
4. `quiz.config.ts` - Quiz setup
5. `daily-reveals.config.ts` - Daily reveals

### Asset Folders
- Photos: `/public/images/`
- Videos: `/public/videos/`
- Audio: `/public/audio/`
